# 🎓 Student Performance Analysis System using NumPy

A beginner-friendly data analysis project built using **Python** and **NumPy**. This project analyzes student performance by performing statistical analysis, ranking, filtering, searching, and array manipulation operations.

---

## 📌 Project Objective

The objective of this project is to understand and apply the core concepts of NumPy by analyzing the academic performance of students.

This project covers almost every important NumPy concept required for beginners and serves as a strong foundation for learning Pandas, Matplotlib, and Machine Learning.

---

## 🚀 Features

- 📊 Generate random student marks
- 👨‍🎓 Student-wise performance analysis
- 📚 Subject-wise performance analysis
- 📈 Class statistics
- 🏆 Class topper identification
- 🥇 Student ranking system
- 🔍 Search students using conditions
- ✅ Boolean Indexing
- 🎯 Filtering using `np.where()`
- ➕ Grace marks using Broadcasting
- ➕ Add new students
- 📌 Insert students at a specific position
- ❌ Delete students and subjects
- 🔗 Merge arrays using `np.concatenate()`
